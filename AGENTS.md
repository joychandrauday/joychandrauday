# AGENTS.md

## What this repo is

GitHub profile README repository. No application code. The `README.md` is the main artifact and renders on the GitHub profile page.

## Structure

- `README.md` — profile page (Markdown + embedded SVGs/images, no executable logic)
- `.github/workflows/generate-snake.yml` — generates snake animation SVGs, pushes to `output` branch
- `.github/workflows/trigger-api.yml` — keep-alive cron pinging `https://api-anycomp.vercel.app/health` every 5 min (external service, not part of this repo)

## Gotchas

- This is **not** an application repo. There are no build, test, lint, or dev commands.
- The `output` branch is auto-generated by the snake workflow — do not edit files there manually.
- `README.md` uses external image APIs (capsule-render, readme-typing-svg, github-readme-stats, etc.). Broken images are usually an external service issue, not a repo problem.
